# Public API inventory

- Coordinates: `TetraPoint`, `TetraGeometry`, `Tolerance`, `Normalization`, `DomainClip`.
- Chart: `TetraplotBuilder`, `Tetraplot`, `Camera`, `TetraFrameConfig`.
- Series: `TetraPointSeries`, `TetraLineSeries`, `TetraSurfaceSeries`, `TetraSurface`, `SurfacePoint`, `SurfaceCurve`.
- Sections: `SectionPlane`, `SectionIntersection`, `PlanarSection`, `SectionTransform`, `TernaryDiagram`.
- Embeddings: `ChartEmbedding`, `PlanarEmbedding`, `TriangulatedEmbedding`, `SurfacePatch`, `BreakLine`.
- Rendering: `RenderedImage`, `Tetraplot::render`, `save_png`, and `show` with the `window` feature.
